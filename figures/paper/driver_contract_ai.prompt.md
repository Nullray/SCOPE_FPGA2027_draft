# Motivation-figure prompt

`driver_contract_ai.png` was generated with the built-in image-generation tool
and checked at the paper's two-column width. Its first, icon-heavy variant was
discarded; the final prompt below produced the image used in the manuscript.

```text
Use case: infographic-diagram. Asset type: camera-ready figure for a two-column ACM computer architecture paper; entirely new image, opaque white background. Design a minimalist abstract CAUSAL TIMELINE of the driver-visible peripheral contract. Wide 2.6:1 landscape. A single hairline horizontal arrow, four evenly spaced vertical ticks, with exactly these bold labels above the ticks: "Discover", "Submit", "Transfer", "Complete". The first tick has a tiny configuration-space grid, the second a tiny queue-entry glyph, the third two parallel thin DMA strokes, the fourth a tiny completion flag. No large boxes and no illustrative clip-art. Under the three inter-tick segments, set exactly these italic labels: "route agrees", "address reachable", "data visible". Above the timeline, a subtle bracket labeled "Native driver". Beneath, a subtle bracket from second to fourth tick labeled "Physical execution". Typography dark navy, linework navy, muted blue for driver bracket and muted green for execution bracket, single orange tick for the mediation boundary. Crisp technical line art, white background, mathematically aligned, generous but not excessive whitespace. Typography sufficiently large for final width 17 cm. No gradients, glow, 3D, shadows, brand names, device models, legends, decorative icons, extra labels, or title. Spell each quoted phrase exactly.
```

The figure is a dependency sketch, not a measured timeline. It should not be
used as evidence that the required ordering has been experimentally verified.
