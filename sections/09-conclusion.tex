\section{Conclusion}
\label{sec:conclusion}

\sys extends peripheral borrowing with a software-selected device view
for an FPGA-hosted processor DUT. It separates DUT-visible device presentation
from physical-device assignment and control mediation from payload transfer.
The FPGA front-end and host back-ends coordinate configuration updates,
physical submission, and completion through C1--C3, subject to the
memory-ordering requirements of the device protocols. Supported endpoints
can be recomposed within the provisioned FPGA capacity while reusing their
DUT software and the FPGA bitstream. RDMA allows physical devices to reside
on remote hosts under the same DUT-visible interface.

Unmodified Linux NVMe and Ethernet drivers operate with physical devices,
and the tested accelerator workloads produce correct results. The evaluation
measures DUT-observed control latency, queue-depth-one NVMe throughput,
and FPGA resource use, and examines local back-end code and driver responses
to injected faults. The evidence supports functional interaction for the
tested operations, with mediation
changing I/O timing. It does not establish timing equivalence to direct
attachment, scaling under simultaneous I/O, or incremental FPGA resource
use per endpoint.
