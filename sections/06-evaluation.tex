\section{Evaluation}
\label{sec:evaluation}

We evaluate SCOPE as a method for software-defined peripheral composition. The
questions are: (1) can a fixed FPGA mechanism expose different logical
subsystems through software configuration, (2) do the two decouplings preserve
native-driver operation, (3) what overhead is introduced by control-semantic
mediation, and (4) which claims are supported by measurements versus
implementation evidence or planned experiments?

\subsection{Experimental Setup and Reporting Boundary}

Table~\ref{tab:platform} records the platform facts needed to interpret the
measurements. The reported results combine two measurement families. Proxy
Forwarding measures the latency visible at the DUT when a BAR transaction is
sent through the FPGA event path and host coordinator. Direct Control measures
the requester-visible MMIO write path without the semantic proxy. They are
therefore not interchangeable metrics. The same distinction applies to the
separate NVMe BAR-write/doorbell experiment: its effective submission includes
queue preparation and semantic translation and is not a device-internal
completion time.

constant while changing only the QEMU backend configuration. Each active

\subsection{Network Functionality and Performance}

The single-queue 82580 backend reaches 56.65\,\si{\mega\bit\per\second} from the
DUT to a peer and 46.82\,\si{\mega\bit\per\second} in the reverse direction for
TCP. The corresponding UDP rates are 4.90 and 7.75\,\si{\mega\bit\per\second},
and ping RTT is 2.80\,\si{\milli\second}. These
values establish a translated TX/RX path, not line-rate Ethernet. Datagram
size, stream count, loss rate, and a direct/on-board NIC baseline must accompany
the final result; they are not inferred from the throughput numbers.

\subsection{FPGA Cost and Capacity Scaling}

The implementation evidence supports a qualitative claim: adding a supported
endpoint adds generic route/configuration state and a software adapter, rather
than copying a complete device controller into RTL. It does not yet support a
quantitative resource-scaling claim. The required synthesis experiment is
shown in Table~\ref{tab:resource-plan}; every row must use the same Vivado
constraints and report both absolute resources and the incremental slope.
